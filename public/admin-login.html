管理员登录
设置页与监控台受密码保护，仅管理员可访问。
# 在服务器上执行：
sudo bash -c 'echo "ADMIN_PASSWORD=你的强密码" > /etc/autofill.env'
sudo chmod 600 /etc/autofill.env
sudo systemctl restart autofill

# 确认已生效（应显示 ✅ 已启用）
sudo journalctl -u autofill -n 15 --no-pager | grep 管理端
密码由服务器环境变量 ADMIN_PASSWORD 配置；修改后需重启服务，旧会话自动失效。
